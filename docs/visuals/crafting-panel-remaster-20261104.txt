图纸锻造面板重制
日期：2026-11-04（Asia/Singapore）

参考与范围
- 视觉参考：docs/visuals/forge-panel-ideal-reference-20261104.png。
- 地图图纸锻造界面使用原生 UGUI，沿用地图的深绿、黄铜、木纹、藤叶与翠色宝石。
- 左侧图纸、中部成品、右侧材料；使用实际图纸、武器、材料精灵。中央成品预览读取 targetWeapon.icon，卷轴独立读取 DisplayIcon。
- 图纸配置仅补齐缺失图标；材料需求、成品、稀有度与锻造结算保持现有配置。

多图纸交互
- 只有一张图纸时，保留参考图的大卷轴和说明。
- 两张及以上时，左栏展开为约五行的可滚动列表，每行显示卷轴缩略图、图纸名和可锻造／缺材料／缺金币／暂不可用状态。
- 金色选中行与翠色标记同步切换中央成品、图纸说明和右侧材料。说明可独立滚动，保留当前图纸完整名称。
- 条目按资产引用绑定，支持同名、同 ID 的不同资产；忽略空条目和零数量图纸。
- 锻造后原位更新全部图纸的可用状态，保留选中项与列表滚动位置，便于连续制作。

校验与反馈
- 材料合并、金币费用、验证与结算仍统一使用 RunCraftingService；只有实际存在的灾厄附加费用才显示金币行。
- 缺材料使用珊瑚红数量；条件满足使用翠色数量。材料多于可见区域时独立滚动，不遮挡按钮。
- 开合使用渐显、缩放与轻微位移；选中切换使用短暂淡入和位移；按钮提供悬停提亮和按压回弹。
- 锻造成功后成品轻微回弹，刻印泛光并散出少量金色火星；结果文字保留，材料与背包立即结算。
- 动效和交互反馈使用 unscaled 时间，暂停时也可正常操作。
- 成功反馈期间短暂防连点；点击时再次验证真实资源，处理函数存在重入保护。
- 关闭动画结束前保留全屏遮罩与地图阻挡；结束后只发送一次 Hidden，重新打开时清理旧结果与失效选择。
- 宽屏、平板与屏幕安全区适配包含顶部标题和铁砧装饰。

视觉对齐与图纸补齐
- 背包格子、物品详情与锻造面板共用 MapItemIconFit，按导入精灵的可见网格等比居中，消除源图透明留白与非居中 pivot 的影响。
- 直接复用精灵顶点、三角形和 UV，不读取运行时纹理、不生成纹理副本；源图、资产 pivot、战斗场景精灵及世界尺寸不受 UI 适配影响。
- 中央武器与刻印使用同一展示矩形；按钮围绕中心按压与回弹，锻造按钮的图标和文字作为一组居中。标题与成品名按文字实际几何高度对齐。
- 补齐 103 烬吻之卷、104 刹影之卷、302 蚀夜之卷的正式透明羊皮纸图标；当前 20 张图纸均配置独立卷轴图，不再回退到成品武器图。
- 新图使用内置 image_gen，生成的 alpha 原样保留；提示词和参考源见 crafting-scroll-icons-20261104-prompts.json。

复现与验证
- 编辑器预览：MapCraftingVisualTools.CaptureDefault()，或菜单 Tools/Map Visuals/Capture Crafting Panel。
- 背包预览：MapCraftingVisualTools.CaptureInventory(name, width, height, blueprints, detail, blueprintID)，可检查武器／图纸格子及详情页。
- 预览使用一次性场景和隔离 RunState，不读写玩家存档。
- 本地预览与测试证据：outputs/agent-battle/crafting-panel-20261104/（忽略提交）。
- 正式回归：MapCraftingOverlayTests、MapItemIconFitTests、MapCraftingOverlayPlayModeTests，以及原有 RunCraftingServiceTests。
- 最终结果：Unity MCP 调用 Unity Test Runner，26 项 EditMode 检查全部通过（面板 14 项、图标与资产 7 项、原有结算 5 项）。
- PlayMode：Unity MCP 在实际播放模式逐帧执行 4 个 UnityTest 协程，4／4 通过，覆盖原生射线点击、触摸拖动、独立材料滚动、暂停动效、防连点、共享材料状态刷新、关闭遮罩与重新打开。
- 最终画面核对：单图纸（烬吻、蚀夜）、多图纸（材料不足／齐备）、1920×1080、2340×1080、1600×1200、安全区域、背包武器／图纸与图纸详情。截图和完整结果保留在本地证据目录。
- 最终控制台错误为 0。验证后恢复原播放选项与运行快照，保留用户原有菜单编辑状态和项目设置；动态字体测试缓存不纳入提交。
