# 资源关键词显示规则

更新日期：2026-11-02（Asia/Singapore）。承接事件面板重制后的资源关键词优化。

## 统一规则

| 关键词 | 文字颜色 | 配套图标 |
| --- | --- | --- |
| 金币、金钱 | 金色 `#F0CC6B` | `Coins` 硬币 |
| 行动点 | 绿色 `#9EDBB8` | `Footprint` 足迹 |
| 钥匙 | 浅蓝色 `#B8D9E6` | `Key` 钥匙 |
| 经验值、经验、EXP（英文大小写兼容） | 淡蓝紫色 `#B8C9F4` | `MapUI/ExperienceStar` 四角星晶 |

图标跟随文字字号缩放，与对应关键词保持在同一行。全文每次出现这些词时应用同一规则；保留原有删除线、富文本属性和不解析区域。资源不足等禁用状态仍由原有交互控制，关键词颜色不替代按钮的禁用状态。

经验关键词由同一个 `ResourceKeywordText` 处理，中文优先匹配完整的“经验值”，避免重复插图标；`EXP` 支持 `13EXP`，不会命中 `Expert`、`DEXP` 等英文单词。星晶另建 TMP fallback 精灵资产，原地图图集的三个索引图标及已有文本精灵索引保持兼容。战斗结算的奖励摘要、角色经验文字及飞行粒子共用这张星晶素材，详见 [战斗结算 UI](battle-settlement-ui.md)。

左上角 `TopLeftPanel` 完全沿用原有资源文字、颜色与独立图标。地图右下角的移动费用单位、已有格子类型图标的标题，以及冒险结算中的固定资源统计行只补充关键词颜色，复用原有或统一后的独立图标，不再插入第二个图标。冒险结算的资源数值也使用对应颜色。

商店重制后，按用户指定的名称稀有度配色，商品卡及详情中的物品名称整段使用实际品质色，其内部不插入资源图标。钱包、商品价格、刷新费用、物品说明和操作反馈继续使用上述资源规则，价格数值一并使用金色。详见 [商店面板实现](merchant-panel-ui.md)。

## 接入与边界

- `ResourceKeywordText` 在 TMP 的 `ITextPreprocessor` 阶段处理显示，原始 `text`、事件回调返回文案、ScriptableObject、奖励和存档数据不写入富文本。动态生成的 TMP 精灵资产复用已有地图图集；已有精灵资产通过克隆加 fallback，保留原索引图标并避免修改导入资产。字体与精灵缓存按运行生命周期清理。
- 统一接入事件标题／正文／选项／费用／不可选原因／后果／结果，地图提示和物品详情，商店、锻造、宝箱、灾厄、战斗预览、战斗技能／状态说明、战斗结算与物品详情、营地交互、冒险结算及加载提示。共享物品详情组件也处理场景或预制体提供的标签。战利品和商品名称整段沿用实际稀有度颜色，不在名称内插入关键词图标。
- 旧 UGUI `Text` 页面使用 `ResourceKeywordLegacyText`，保留原有字体、文本 API 和按钮逻辑。只有包含资源词的标签启用 TMP 子文本，普通文案继续使用原组件；首选尺寸按实际显示内容测量。旧教程、能力页、主菜单和暂停页均沿用该路径。
- 事件和地图详情的首选高度使用包含图标的预处理文本，继续保留长文本滚动。商店选中商品和付费刷新按钮采用深绿底配浅色正文，避免固定金色关键词与原金色底混在一起；未改价格、折扣、刷新或购买规则。
- 没有新增或修改敌人、技能、遗物、事件效果、数值、投放和存档格式，无需更新内容目录。最初的关键词优化复用既有地图图标；此次结算重制新增独立透明经验星晶，原始生成图及提示词记录于 [素材出处](experience-keyword-icon-20261102-prompt.txt)。
