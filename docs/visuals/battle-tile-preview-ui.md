# 战斗格子详情预览 UI

日期：2026-11-03（Asia/Singapore）。基于用户认可的 [第二版参考图](battle-tile-detail-concept-v2-20261103.png)，接入实际地图进入战斗前的预览。

## 表现与信息

- 深绿异形牌面、细黄铜边、外伸盾徽和酒红绶带，标题使用项目已有楷体。普通、精英、首领分别复用地图原有剑、交叉剑和头盔图标；无需逐个敌人制作立绘。
- 区域／坐标为次级信息，大标题后是清楚的危险度评级和 `n/8`，再显示至多三个实际属性及探索／解决状态。最高危险度改用深底可读的亮色，仅调整本面板文字表现；评级数值、名称和推断规则不变。
- 属性接入统一关键词注册表，直接使用固定颜色和图标；生命、血量、金币等仍沿用 [关键词规则](resource-keywords.md)。标题、按钮和属性文字均保留实际字体资源引用。
- 进入操作采用酒红底黄铜边按钮；返回为较轻的文字操作，保留完整触摸区域。按用户追加要求，面板去掉行动点消耗和不足的全部说明，进入按钮也不附带费用；真实 `moveCost`、提交前校验及扣点流程继续由原服务／控制器处理。行动点校验失败时保持进入禁用，不显示该原因文字；钥匙不足、其他失败和过期预览保留原提示。
- 长原因有独立竖向滚动，不挤压进入与返回操作。显示预览时暂时收起地图原格子详情卡，资源和队伍栏保留；关闭、取消、失效、停用和切换场景时恢复详情卡原有显示状态。

## 接入与适配

`MapBattleTilePreviewOverlay` 保留原接口、确认／取消事件、可用性和重复显示处理；构建与布局拆至 `.View.cs`。`MapBattlePreviewFrameGraphic` 用 UGUI 网格绘制可缩放牌面、按钮和返回标记。`MapBattlePreviewTheme` 只引用既有字体；`BattlePreviewCrest.png` 是独立透明底图，[素材与完整提示词](battle-tile-preview-crest-20261103-prompt.txt)记录来源。没有保存或迁移正式场景。

`RunGameManager` 配置主题并绑定 `MapHUD` 的详情卡显示管理。原 `MapBattleTilePreviewController` 的镜头、棋子动画、返回、即时清理、提交失败、重复确认保护和战斗交接均保留。

宽屏采用右侧竖牌，600×810 设计坐标；较窄屏／竖屏采用底部 920×520 的横向版式。整体按可用空间等比缩放，考虑上下左右安全区域。字体按实际角色分配，标题与按钮使用楷体，说明使用地图正文字体，属性保留原属性字体及统一图标；不依赖生成图中的文字。

## 验证结果

团结 **2022.3.62t6** 隔离工程最终相关 EditMode **267/267**、PlayMode **27/27** 通过。复用原战斗预览、镜头、棋子、校验与交接回归，并覆盖关键词、地图 HUD、事件、商店、结算和资源反馈。新增检查包括元信息／无费用按钮、详情卡隐藏恢复、长原因独立滚动、原生射线点击返回／进入、确认只提交一次且扣除原有费用、暂停时滚动及返回，以及中文／英文行动点消耗和不足说明隐藏后仍不能提交的检查。原控制器回归继续核对禁用和刷新校验，钥匙原因保留，行动点原因只保留在原上下文数据中。

八张交付画面检查标题、危险度对比度、属性图标、锁定状态和安全边界；收紧了底部按钮位置，减淡纹样，确认普通与首领地图图标随样例类型刷新。验证使用隔离工程，没有停止或改写用户的 Play 状态。正式源码、元数据与素材和隔离工程副本按 SHA-256 校验。
