# 主菜单重制

日期：2026-10-30。以同目录 `main-menu-concept-20261030.png` 为已确认的视觉参考。

## 实现与入口

`MainMenuSceneController` 保留正式存档、开局、教程、能力、设置、制作人员、退出和测试战斗处理。新增 `MainMenuForestView` 负责森林背景、透明标题、八个原生 UGUI 按钮、难度选择和安全区布局；`MainMenuOrnament` 绘制分隔线、小图标与少量漂浮光点。

- 主导航：新游戏、继续游戏、能力、教程、设置。
- 底部入口：制作人员、退出；右下角保留测试战斗。
- 无存档时禁用继续，显示“暂无存档”；可继续时恢复按钮。
- 新游戏先选择实际配置的难度，再按“开始冒险”调用原有开局逻辑；返回或 Escape 取消选择。只打开或切换难度不会删除存档。存在存档时显示覆盖提醒。
- 普通难度配置实际名为 `Medium`，排序时与 `Normal` 同级，显示顺序为简单、普通、困难、极难。地图尺寸与行动点取实际配置，未调整难度数值。
- 打开现有弹窗时关闭菜单输入；原有轮盘保持配置引用，运行时隐藏并停用其输入，避免同时响应。

菜单独立画布排序为 100，低于现有子面板和场景幕布。销毁菜单宿主时清理独立画布。字体引用沿用项目内的 `Hi字楷体简.ttf`；其他现有面板的字体配置独立保留。

## 调整与预览

`MainMenuVisualTools.ConfigureArtImports()` 只配置本菜单的三张纹理，不使用全局纹理后处理器。背景、标题禁用 mipmap，保持原始长宽比，纹理上限 2048；按钮配置透明边距裁切和九宫格。

菜单按屏幕高度缩放，4:3 时适度缩小整组内容。可点击入口全部放在 `Screen.safeArea` 内。背景从左侧取景，优先保留菜单的暗色区域；窄比例会裁掉右侧部分场景。

在打开正式菜单场景时，使用 `Tools/Main Menu Visuals/Configure Menu Font` 配置字体；使用 `Capture Phone Menu` 或 `MainMenuVisualTools.Capture(...)` 生成可复现的离屏预览。预览使用独立临时场景，不操作玩家存档或钱包。

预览图、测试日志和检查记录仅留本地 `outputs/agent-battle/main-menu-20261030/`。编辑器渲染不能替代 Android 真机观感与性能验证。

## 悬停与页面转场（2026-10-30 续作）

五个主导航共用一张九宫格羊皮纸金框，初始停在“新游戏”。鼠标进入、选中或触摸按下时更新目标；离开按钮后保留最后焦点，跨过行间空隙时不会反复跳回首行。无存档的“继续游戏”不能获得焦点。底部工具入口保留各自的轻量高亮。

金框采用不受 `Time.timeScale` 影响的阻尼追随，平滑参数为 0.075 秒；途中改换目标时保留当前位置和速度。轻按缩至 98.5%，松开或移出恢复。主导航文字加粗，文字、图标和投影按金框的实际位置连续变色，避免金框到达前文字先变暗。金框不接收射线，点击区域保持固定。

主菜单与难度页交叉淡入并轻微侧移，难度页在淡出结束后才隐藏；进入途中按 Escape 可以平滑返回。转场期间拒绝旧页面的点击和提前启动请求；开始冒险仍只执行一次。

能力、教程、设置、制作人员页面复用 `MainMenuPageMotion`。进入时从右侧 48 个参考像素淡入，返回时向右侧 36 个参考像素淡出，分别使用 0.07／0.055 秒的阻尼平滑参数。主菜单的标题和导航同步淡出、左移，森林背景保留；返回时恢复。关闭过程中保持页面可见并锁住输入，待动画结束才执行隐藏与返回回调。重复关闭不会重复回调；动画途中重新显示会从当前姿态续接并取消旧的关闭回调。时间缩放为零时仍可完成动画。

教程的返回回调统一在实际关闭后执行；开始教程拒绝进入动画期间的点击和重复启动。四种子页面销毁宿主时会清理独立画布。编辑模式预览保持立即切换，已有预览和 EditMode 调用方式可继续使用。

`MainMenuVisualTools.Capture(...)` 新增可选的 `focus` 和 `hoverSeconds` 参数，可复现指定按钮的悬停终态或途中画面。验证记录见本地 `motion-validation.json`。

最终相关 EditMode **45/45**，新增 PlayMode **7/7**。运行时检查包含真实帧追随与途中改向、时间缩放为零、难度页淡入中返回、阻止提前／重复启动、子页面关闭回调时机、重开取消旧关闭回调，以及能力／设置／制作人员页面的实际组件往返和宿主销毁清理。教程还验证了进入期间禁用启动及连续点击只启动一次。

测试使用本地隔离工程；12 份相关实现、工具和测试文件与主工作区逐一核对一致。隔离工程使用独立产品名隔开持久目录，并仅在隔离工程移除会中断批处理 PlayMode 的版本控制编辑器插件；正式工程的包配置和玩家档案保留。未扩大为全套回归，也未重新打包或进行手机验证。

另在隔离工程运行复制的正式 `Menu Selection` 场景及四份正式难度配置，经实际 `MainMenuSceneController` 检查八个入口、能力／教程／设置／制作人员的进出场和输入恢复，以及难度页的四行配置与返回。六张离屏 UGUI 渲染已查看，覆盖 2340×1080、1920×1080、1600×1200、悬停终态／途中与正式难度页。玩家原有持久文件的前后 SHA-256 一致。完整清单保留在本地验证 JSON，场景检查未开始新冒险、读取继续存档或购买能力。
