DiceLand 教程 UI 重制实现记录
日期：2026-11-05（Asia/Singapore）

统一视觉
- 主菜单的开始确认与教程目录、地图各步骤提示、战斗教学和反馈，均使用 TutorialForestView。战斗和地图的单纯操作高亮使用同一套遮罩与焦点线条。
- 确认页使用地图、骰子与指南针插画，保留原说明与学习主题区；金色“开始教程”与木质“返回主菜单”区分主次。完整教程目录仍可滚动阅读。
- 地图和战斗提示使用更紧凑的深绿金边窗口、木质标题牌、米白正文与金色“继续”按钮，保持原有标题、说明、按钮标签和教程顺序。原配置的 legacy Font / TMP Font 继续生效。
- 已有资源关键词配色保留，教程正文减少重复图标。坐标和类型的引导区使用金色和淡珊瑚色区分重点。
- `Assets/Resources/TutorialUI/` 包含无字 ForestWindow、WoodTitle、AdventureGuide。内置 image_gen 生成，原样复制、保留透明边缘。底框使用九宫格，按钮复用 MainMenu/GildedButton；所有文字、图标、遮罩和按钮仍由 UGUI 实时排版。
- 完整生成提示词、资产原文件、尺寸、哈希和导入参数见 tutorial-ui-assets-20261105-prompts.json；完整设计参考见 tutorial-popup-design-20261105.txt。

真实目标与安全区
- 地图教程各步读取实时 HUD：行动点单元格、金币单元格、资源面板、名称和坐标行、探索状态、移动消耗、说明视口；地图格及战斗操作目标保留真实投影并持续跟随其位置。
- 将实际目标四角投影到屏幕，再转换进教程画布的局部坐标，尊重所属画布相机、可视范围及祖先裁剪；移除地图固定锚点和横纵分别缩放的旧路径。
- 高亮框和镂空遮罩使用同一个最终矩形。目标离开可见范围时撤下高亮，不留空白点击洞。解释弹窗期间拦截背景及高亮洞的输入；纯操作高亮阶段保留原有目标点击限制及地图拖动、缩放规则，战斗点击范围随实际目标更新。
- 布局或屏幕大小变化后重新定位；提示卡在目标周围寻找空间，避开所属 HUD 或格子面板并保持在安全区内。窄屏确认页允许改为上下排版；长说明滚动，按钮固定。

开合与交互
- 窗口使用不受教程暂停影响的淡入淡出、轻微缩放和位移，打开0.22秒、关闭0.16秒；现有按钮反馈负责悬停和按压，焦点光晕只改变亮度。
- 继续、开始、返回的回调在收起动画结束后执行；重复点击不重复推进。原地图和战斗的暂停值及输入限制在关闭后恢复；程序直接隐藏及场景销毁可立即清理。
- 保留控制器／键盘焦点，关闭恢复先前有效焦点；菜单取消绑定返回，教学阶段仍只提供原有“继续”。
- 不改教程战斗配置、敌人数值、技能机制、遗物和玩家存档，无需同步内容目录。
