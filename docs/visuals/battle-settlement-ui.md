# 战斗结算 UI 重制

更新日期：2026-11-02（Asia/Singapore）。依据用户确认的 [含金币参考图](battle-settlement-rewards-concept-20261102.png) 实现正式 UGUI/TMP 面板。

## 界面与交互

- 森林绿面板、黄铜边框与角饰，保留战斗胜利／失败、剩余可行动人数、重试与返回。正式战斗场景的结算字体与地图统一。
- 顶部三项奖励：金币、经验值、战利品种类数；每项堆叠数量仍在物品格内单独标注。金币与经验值通过地图共用的 `ResourceKeywordText` 显示对应图标和颜色。
- 队伍卡展示实际角色头像、名字、等级、HP、经验值及进度条；倒下角色仍标明状态。较长名字换行，较多角色在队伍区单独滚动。
- 战利品为三列网格，常见六件奖励完整展示两行；更多奖励独立滚动，长名称按所需高度扩展。名称颜色读取实际 `LootRarity`，不会根据图标颜色猜测品质。点击打开既有物品／遗物详情。
- 精英遗物选择入口、候选刷新、强制选择和确认逻辑继续生效。动画中可直接点击重试或返回；先补齐显示终态，再执行原流程，未选择必需遗物仍会被拦截。

## 动效顺序

1. 原场景配置的胜利入场结束后，面板显示；金币、经验值、战利品计数在 0.7 秒内同时从零增长。
2. 计数完成，所有角色的经验组同时从经验奖励栏出发；每组按该角色实际所得经验加权，飞向各自经验条。条内平滑增长并按实际等级阈值跨档，落点有淡蓝扩散光环和星芒。
3. 同时临时钱包由屏幕顶部下拉，再调用地图原有的金币散开、飞行、落袋细节、音效与到账数字。显示到结算后余额后短暂停留，再上拉隐藏。
4. 与经验／金币转移动画同时，战利品按顺序从占位状态显露图标、名称和数量；完全显露后可点击查看。

使用非缩放时间，游戏暂停时仍能完整播放。经验粒子复用缓存，通常每角色最多八颗，随队伍人数降低单组粒子数；粒子权重的总和始终等于该角色实际所得经验。较多角色滚出可视区域时，飞行终点限制在队伍视窗内，数值仍准确更新。隐藏、销毁、重开及提前完成均清理飞行物、落点反馈与钱包，特效不参与射线点击。

## 数据来源与边界

- 金币读取已由战斗流程及灾厄修正计算好的 `BattleEncounterData.moneyGained`，败北显示零；不另造固定金币奖励。
- `MapRunRuntime.TryGetMoney` 只读取同源地图的结算前余额，避免克隆整张地图。临时钱包绑定独立展示状态；金币真实发放仍由返回地图时的既有 `ApplyEncounterResult` 负责。
- 无对应地图快照时，钱包标为“本次获得”，仅展示本场金币，不虚构持有余额。负余额可如实显示。
- 经验与最终 HP／等级／经验进度由原战斗成长服务预先结算。工厂补充头像和每级阈值用于展示；包括倒下角色在内，继续遵循现有经验分配规则。本次没有修改奖励、升级、重试或存档规则。
- 经验星晶保存原始透明生成 PNG，Unity 导入上限 128 像素；通过独立 TMP fallback 使用，原地图图集三个索引不变。[提示词与校验](experience-keyword-icon-20261102-prompt.txt)。
- 未新增或修改敌人、技能、遗物、数值和投放配置，无需变更内容目录。

## 复现

编辑器菜单 `Tools/Battle Visuals/Capture Settlement Panel`，或批处理入口 `BattleSettlementVisualTools.BatchPreview`。输出到已忽略的 `outputs/agent-battle/settlement-ui-20261102/`；在隔离工程运行时，输出位于该工程内同名目录。

工具在临时预览场景使用正式面板、正式头像和正式物品图标，以合成结算数据展示计数、转移、钱包、完成状态及多物品／败北变体。不会进入正式战斗、执行领取、保存场景或写入玩家存档。样例中每名角色获得 13 经验，按其初始进度和阈值计算终态，不把参考图中的静态数字当成玩法配置。
