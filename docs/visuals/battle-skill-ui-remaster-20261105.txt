DiceLand 战斗技能界面重制接入
日期：2026-11-05（Asia/Singapore）
状态：我方技能选择、敌方当前技能与右上角悬浮摘要已接入原有入口。
参考图与完整生成提示词：battle-skill-ui-design-20261105.txt、battle-skill-ui-20261105-prompts.json。

实现范围
- 原 BattleSkillInfoOverlay 的脚本身份、Show／Refresh／Hide API 与事件保留。
  布局、内容和动效拆为 Presentation、Content、Motion 三个 partial 文件。
- 沿用 MapCraftingFrameGraphic、MapItemDetailFrameGraphic 与 MapMerchantFrameGraphic 的
  森林绿、黄铜、木纹和装饰语言；BattleSkillFrameGraphic 提供选中卡片、类型、骰子与勾选图形。
  运行界面使用独立原生 UGUI 文本、按钮、图形与滚动视口，参考 PNG 继续作为设计资料保留。
- 沿用场景配置字体与 ConfigureFonts 接口；已装备勾选使用图形，避免字体缺字。
- 只读规则生成改为复用逐骰 BuildDiceRuleLines，完整词条与公开 DescribeSkillRules
  仍使用同一套实际格式器。分卡片不靠切分整段详情字符串。
- 本次未改变技能或敌人数值、效果、触发条件及投放配置；目录记录内容没有变化，
  不改写敌人／遗物目录或历史快照日期。

三个入口
我方技能选择：
- 左侧真实武器／临时技能列表，显示名称、能耗、骰子概况、当前选中与施放需求。
  能量不足及状态不足沿用 BattleButton 的实际可用性校验，并在点击时再次校验。
- 按来源速度按钮切换技能，保留多速度槽独立选择；点击即可生效。
- 列表更新复用现有按钮，避免指针按住时销毁按钮；超长列表独立滚动，
  初次打开或选中项变化时将该项滚入可见区域。
- 保留角色、武器及临时技能上下文；暂未配置技能时显示明确空状态。

敌方当前技能：
- 单列只读布局，无技能列表占位；保留名称、能耗、骰子数、范围、全部词条与描述。
- 刷新继续读取原来源速度按钮的已选技能，避免多速度槽查看时跳回第一个槽。
- 原有敌人详情模式也继续支持名称、最大生命、说明及被动文案。

右上角悬浮摘要：
- 固定在安全区右上方，短内容按需收缩；标题、敌人上下文和全部骰子范围固定。
- 词条采用独立限高视口，保持既有顶部停留 3 秒、24 像素／秒、
  底部停留 3 秒后复位的自动阅读行为，使用非缩放时间。
- 每 0.2 秒检查当前技能和有效范围；相同词条不重置滚动，
  切换来源时复位，旧来源的离开事件不会隐藏新摘要。
- 不接管战斗输入；移出来源隐藏，打开完整弹窗时隐藏，战斗执行／演出锁继续生效。
- “无词条”作为普通占位文字处理，避免被属性关键词系统加入无属性图标。

多骰、长内容和适配
- 按每颗实际索引读取类型、基础范围、当前有效范围与完整效果；
  支持攻击／防御混合、旧值删除线、条件数值、延迟、召唤、阶段变化及跨骰规则。
- 多骰时保留顶部骰序概览，点击概览可定位对应卡片；正文按骰序纵向滚动。
  跨骰 +2 等尚未触发的规则继续作为条件词条显示，不提前加到下一骰范围。
- 描述和全部词条使用自然换行与真实内容高度；正文不缩小字号来挤入固定高度。
- 详情与列表各自滚动，标题、骰子总览和关闭按钮固定；切换技能复位详情，
  同一技能刷新保留阅读位置。短内容从首帧起隐藏滚动条。
- 面板与标题牌按安全区缩放定位，已检查宽屏、16:9 安全区与 4:3 平板画面。

动效与输入
- 完整面板约 0.22 秒淡入、轻微缩放与上移；关闭约 0.16 秒。
- 内容切换约 0.16 秒淡入，悬浮摘要约 0.12 秒淡入与轻微位移。
- 按钮沿用 MapCraftingButtonFeedback 的非缩放时间悬停／按压反馈。
- 关闭动画结束前持续阻挡底层点击并保持速度按钮输入抑制；
  重开取消旧关闭，隐藏事件只触发一次，禁用与销毁会释放本组件拥有的输入锁。
- 战斗自动关闭使用 Hide(false) 的即时路径；恢复可用的原 EventSystem 选中对象。
