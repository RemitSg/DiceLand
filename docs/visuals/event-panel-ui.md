新增正式“发光的树洞”事件检查，与用户截图保持同一资产和 2048×943 比例。场景回归验证原组件深色底与正文的对比度、大阅读区、完整文字、三项选择、区域分离及安全边距，防止旧序列化覆盖再次漏检。较多选项继续通过内部滚动显示。

## 实现结构与布局

- `MapEventOverlay.cs` 保留事件选择、费用／条件预览回调、执行失败、结果页、继续／关闭和嵌套事件深度限制。确认文案修正为正常中文“确定／继续”。费用与不可选原因完整展示在效果区，选项名称保留“不可选”标记。
- `MapEventOverlay.View.cs` 负责深绿底、象牙色正文、暗金分隔、大幅通栏阅读区、紧凑横排选择和底部后果预览。常规两项短选项时，阅读区约占面板高度的 46%；正文为 32 基准字号，选项效果／后果为 28，不通过缩小字号或省略内容容纳长文。
- 标准面板为 1280×920，基于 1080 屏幕高度布局，随横屏安全区域整体适配。标题可换行，选项根据名称和完整效果的实际字体高度增高；长行采用顶部对齐。选项区最高 230 基准像素，超过后在内部滚动，避免占尽叙事空间。
- 说明、选项、后果预览各有独立的原生 `ScrollRect`／`RectMask2D`／滚动条，支持拖动和滚轮；短文本隐藏滚动条，滚动条出现时不改变正文宽度。新事件、切换预览和结果页重置相应滚动位置。结果页隐藏选项并扩大正文。
- 资源关键词统一按 [资源关键词显示规则](resource-keywords.md) 添加行内图标与固定颜色，叙事、费用、不可选原因、后果和结果均适用；首选高度包含图标宽度，原始事件文本和效果配置保持原样。
- `MapEventChoiceGraphic.cs` 绘制切角选项边框、序号分隔、单选环和勾选状态。`MapEventFrameGraphic.cs` 绘制细黄铜框与金色确认按钮，避免把旧地图边框的藤蔓拉长。均为可缩放的 UGUI 网格，没有逐事件插画、道具图或新增位图素材需求。事件资产原有 `eventIllustration` 字段保留，当前通用面板不显示插画。
- 全屏暗幕继续高于地图 HUD 并拦截底层点击；只选择事件选项时不会执行事件效果，实际效果仍由原回调执行。
