# 林间商店面板重制

更新日期：2026-11-02（Asia/Singapore）。参考为已确认的 `merchant-panel-concept-20261102.png`，并按用户要求以商品名称颜色表现实际稀有度。

## 正式接入

`RunGameManager.GetOrCreateMerchantOverlay()` 继续使用原有 `MapMerchantOverlay`，通过现有字体配置和购买／刷新／费用回调接入。界面由真实 UGUI、TMP、按钮和滚动组件构建，参考图不作为整张面板贴图使用。

- `MapMerchantOverlay.cs` 保留库存、选择、钱包、实际价格、可购买状态和回调处理；`MapMerchantOverlay.View.cs` 负责布局与展示。标准面板为 1540×950，按 1080 高度参考空间适配横屏及安全区域；较窄屏幕整体缩放，面板保留安全边距。
- 深绿底、象牙色正文、细黄铜框，顶部为商店图标、标题、钱包和关闭；左侧双列商品卡，右侧物品图标、名称、类型／稀有度、完整效果、遗物附加说明及操作反馈。底部保留刷新商品与离开商店，右下角固定购买价格与购买按钮。
- 价格、钱包、刷新费用和完整说明沿用 [资源关键词显示规则](resource-keywords.md)。商品原价与折后价由 `RelicMerchantService.CalculateOfferPrice()` 提供；有折扣时保留划线原价。资源文字使用深色背景，金色购买按钮使用深色文字。
- `MapMerchantCardGraphic` 绘制多层黄铜切角卡片、明暗斜面、内沿与角部扣边，以及玉绿选中底、亮金边和圆环勾选；售罄以暗底、淡化图标及独立“已售罄”标签框表示，仍可选择并查看完整说明。名称颜色始终取实际商品资产的稀有度，选中与售罄均不覆盖它。
- 商品与详情图标下均有独立的暗色衬框、隐约的内沿和细角饰；类型／稀有度带有小型底板。标签、名称、图标框和价格各自留有间距，长名称不会挤进图标或选择勾选。
- `MapMerchantFrameGraphic` 统一绘制主面板、内凹详情／价格区、图标衬框、标签、钱包、绿色刷新按钮和棕色离开按钮，补齐黄铜斜边、阴影、细角饰、微弱纹理、外框叶饰与菱形分隔。金色购买按钮按参考图增加宽度、厚边和字号。128×128 的共享细纹由固定种子在运行时生成并按生命周期释放，不依赖外部图片或新材质资产。
- `MapHudGlyph` 增加绘制的刷新箭头，避免中文字体缺少箭头字形。本次商店边框独立实现，原事件面板边框没有改动。
- 商品列表和详情各使用独立的 `ScrollRect`、`RectMask2D` 和原生滚动条，支持拖动与滚轮，并在暂停时间下工作。长名称按真实字体首选高度增加整行卡片高度，完整说明不截断、不自动缩小字号。长说明滚动时，购买区始终可见；短内容隐藏滚动条。
- 全屏暗幕位于地图 HUD 上方并拦截底层点击。选择商品只更新详情；购买、刷新分别调用原回调，购买可用性继续由 `MerchantPurchaseService.EvaluateOffer()` 决定，保留正余额赊购等既有遗物规则。操作后重新绑定库存、钱包、选择、售罄／余额状态及完整反馈；操作保护避免回调重入。
- 关闭按钮和离开商店均调用原隐藏通知；重复隐藏只通知一次，关闭后暗幕释放射线。空库存显示明确说明，并禁用购买及刷新。

## 名称稀有度配色

卡片和详情共用原有配色解析；战利品、图纸、遗物使用 `LootRarity`，武器使用 `Rarity`，不依据商店位置、价格或样例名称推断品质。

物品名称中的“金币／行动点／钥匙”等字样也完整保留稀有度颜色，不插入资源图标；价格、费用、说明与反馈继续使用统一资源关键词规则。

| 实际稀有度 | 名称颜色 | 色值 |
| --- | --- | --- |
| Common／普通 | 灰 | `#808080` |
| Uncommon／优秀 | 绿 | `#38B256` |
| Rare／稀有 | 蓝 | `#407EFF` |
| Epic／史诗 | 紫 | `#A35CFF` |
| Legendary／传说 | 金 | `#E6B42C` |
| Trash（沿用已有标签；武器无此项） | 棕 | `#7E5330` |
