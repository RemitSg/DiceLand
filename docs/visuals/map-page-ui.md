# 地图页面森林遗迹 UI

更新日期：2026-11-02（Asia/Singapore）。本次接续地图参考图落地任务。

## 目标与正式接入

沿用已确认的 `map-page-concept-20261102.png`，将地图页统一为森林遗迹背景、深绿面板、暗金边框和同一套格子图标。参考图的布局示例为 7×7，正式游戏仍按原难度配置生成 7／9／11／13 格棋盘，未固定生成参考图中的格子内容。

- `MapHUD.cs` 与 `MapHUD.Forest.cs`：资源分栏、队伍卡片、右下详情卡和安全区域布局。难度占右侧独立整列，金币和钥匙分别占底部两格。标题、数值、状态与描述均为真实 UGUI／TMP，未使用整张参考图替代界面。
- 队伍栏：保留生命、经验、等级和折叠操作；短队伍不保留巨大空底板，超高列表可滚动。
- 详情卡：类型图标、名称、坐标、探索／解决状态、独立移动消耗条和说明区。敌方属性、危险度、区域、预览标签等原有信息保留，长说明使用滚动区域。切换格子时重置滚动，清空选择时隐藏状态和消耗。
- `MapForestArt.cs`、`BoardManager.cs`、`BoardTileView.cs`：按实际格子类型读取统一图标，使用石质格底、克制的类型配色和选中提示；已探索、持续存在、Boss 解锁等原有规则继续由原逻辑决定。副本出口保留原图标回退。
- `PlayerMapController.cs`：棋子优先使用现有角色战斗立绘或角色预制体中的精灵，最后回退为头像；棋子外框限制在单格内。原移动、跳跃与战斗预览机制保留。
- `MapViewController.cs`：总览镜头将完整棋盘放在两侧面板之间，保留拖动、缩放、出生镜头和战斗预览。

正式场景通过原有组件自动使用这些资源，无须改写地图场景或运行时存档。

## 行动点与四时段背景

`MapBackgroundController` 的既有阈值和流程保持不变：

| 使用位置 | 条件 | 正式资源 |
| --- | --- | --- |
| 地图清晨 | 剩余行动点比例 ≥ 60% | `ForestMorning.png` |
| 地图正午 | 比例 ≥ 20% 且 < 60% | `ForestNoon.png` |
| 地图傍晚 | 比例 < 20%，包括耗尽时的地图底层 | `ForestDusk.png` |
| 灾厄选择界面 | 由 `RunGameManager` 原有流程调用 `GetBlurredMidnightBackgroundSprite()` | `ForestMidnight.png` 的模糊版本 |

午夜不是新增的地图阈值。原有黑场切换、行动点消耗和灾厄触发逻辑未改。背景随镜头缩放与横屏比例变化重新铺满；普通地图背景保留画面细节，灾厄底图继续使用原模糊逻辑。

## 美术资产与复现

正式资源位于 `Assets/Resources/MapUI/`，包括四张背景和一张透明图集，全部携带 `.meta`。

图集包含 16 个命名子精灵：`Sword`、`Elite`、`Event`、`Merchant`、`Treasure`、`Forge`、`Rest`、`Key`、`Boss`、`Footprint`、`Compass`、`Coins`、`TileFace`、`PanelFrame`、`PartyCard`、`ButtonFace`。小型眼睛、勾选、书本与分隔线由非交互 UGUI 网格绘制。

参考图和五项正式美术均来自前序对话的内置 image_gen。本次续作复用已有 PNG，没有重新生成或修改位图。提示词分别保存在 `map-page-concept-20261102-prompt.txt` 和 `map-ui-asset-prompts-20261102.txt`。角色图像复用项目资产。

编辑器入口：

- `Tools/Map Visuals/Configure Forest Art Imports`：设置图集切片、九宫格边距和背景导入参数。使用 Sprite Editor 数据接口并保留既有精灵 ID。
- `Tools/Map Visuals/Capture Forest Map`：在临时预览场景渲染正式组件，输出清晨 2340×1080 预览，不使用玩家存档。
- 批处理 `MapVisualTools.BatchPreview`：生成四时段美术预览、1920×1080、1600×1200、2340×1080 敌对详情及 2400×1080 安全区域样例，共 8 张。午夜图为背景美术检查，实际灾厄界面的引用另由 PlayMode 测试验证。参考格子布局和固定队伍数值仅用于该预览工具。

临时截图、隔离工程、测试 XML 和日志保存在已忽略的 `outputs/agent-battle/map-ui-20261102/`，不随正式资源提交。
