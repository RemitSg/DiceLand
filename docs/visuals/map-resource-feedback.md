# 地图金币与生命动效

更新日期：2026-11-02（Asia/Singapore）。承接林间商店重制后的 UI 动效需求。

## 正式接入

`MapHUD.Initialize()` 在运行时自动创建／复用 `MapResourceFeedback`。`Refresh()` 比较已展示的金币和队员生命，初次绑定、切换冒险和重新显示时直接呈现当前值。没有新增场景引用、存档字段或奖励结算逻辑。

- 获得金币时，先从实际来源处散开，再沿弧线加速飞向左上角金币数量。数量为 `ceil(sqrt(增量) × 1.8)`，最少 1 枚、最多 18 枚，且不超过实际增量。每枚按整数权重代表部分奖励，到达后才计入显示数量，最终总额精确一致。到账有金色光环、闪点、数字轻微弹动和逐步升高音调的清脆音效。
- 扣款时数字立刻变红，在约 0.48 秒内平滑递减到目标值，再恢复原有颜色和大小；同时显示扣款浮字和较低的金币音。保留已有允许负余额的赊购结果。
- 事件确认从可见“金币／金钱”字样取坐标，缺少字样时使用确认选项位置；宝藏从奖励详情文字或卡片取坐标，商店购买／刷新从对应价格文字或按钮取坐标。坐标在执行回调前捕获，结果页替换文字或关闭面板后仍然有效。滚动裁剪外的文字不会成为来源；没有明确 UI 来源的间接收入从画面中部发出。仅选择、预览或重复刷新 HUD 不会发放金币或播放获得动画。
- 连续收支按顺序显示，最多保留 4 个待处理变化；超过上限时合并最后一段至最新真实余额。飞行金币池最多 18 个，浮字／光环也有回收上限。新冒险、隐藏 HUD 或销毁 HUD 会清除旧动画并收敛到最新余额。
- 队员生命在约 0.48 秒内平滑变化，数字同步过渡；受伤保留最长约 0.84 秒的金橙残影，回血短暂转绿，并有红／绿浮字、短音效和渐隐的屏幕边缘反馈。画面中央保持透明，不移动地图相机。中途再次受伤或回血从当前显示值接续，队员换位或替换时重新绑定，不沿用其他成员的旧血量。
- 动效使用 `Time.unscaledDeltaTime`，时间倍率为零时仍正常运行；来源与目标通过实际 Canvas 坐标换算，钱包位置变化时飞行目标会跟随。独立反馈 Canvas 位于事件／商店上方，没有射线组件，所有装饰均不接收点击，保留原生地图／按钮／滚动操作。

真实资源、费用、购买可用性和存档仍由原服务立即结算；动效仅延迟展示数字，不反写 `RunState`。一次 HUD 更新观察到的是该操作的实际净变化，未把同一回调内部抵消的收支虚构成额外奖励。

## 素材与音效

- `Assets/Resources/MapUI/FeedbackCoin.png`：上一个断点已通过内置 image_gen 生成的透明单枚金币，原图原样接入，导入上限 256px、单精灵、无 mipmap、双线性／Clamp。完整提示词和原图哈希保存在 [金币素材记录](map-feedback-coin-prompt.txt)。价格／钱包原有金币堆图标保留。
- `Assets/Resources/SFX/MapCoinRelease.wav`、`MapCoinArrival.wav`、`MapCoinSpend.wav`、`MapDamage.wav`、`MapHeal.wav`：五个原创程序合成短音效，分别用于散开、到账、支出、受伤和恢复。使用 `tools/ui-preview/Generate-MapFeedbackAudio.py` 可确定性复现；不依赖录音、外部服务或额外密钥。单声道 44.1kHz PCM16、0.18～0.52 秒、峰值 0.62，边缘淡入淡出。
- 2D 音效沿用 `MainMenuSettingsPersistence.Current.sfxVolume`，静音时不创建播放源；连续到账限速，避免同帧叠加大量声音。组件提供可选 AudioClip 覆盖。背景音乐和原音量设置不变。
- `MapFeedbackGraphic` 绘制光环、闪点与透明中心的边缘网格，显式要求 `CanvasRenderer`；没有新增特效纹理或材质资产。

## 复现与检查

在同版本团结 2022.3.62t6 隔离工程运行：

```text
-batchmode -quit -executeMethod MapResourceFeedbackVisualTools.Capture
```

编辑器菜单为 `Tools/Map Visuals/Capture Resource Feedback`。工具复用正式地图 HUD、事件面板和反馈组件，在临时预览场景输出 2340×1080、24fps、150 帧序列及 `feedback-trace.csv`、`preview-complete.json`。顺序为事件领取 107 金币、扣除 75 金币、受伤、恢复。样例运行数据和叙事仅用于检查，不写入事件资产或玩家存档。

可用带 Pillow 的 Python 执行 `tools/ui-preview/Build-ResourceFeedbackPreview.py <帧目录> <输出.gif>`，生成 1170×540、12fps 的无声预览。GIF 不能用于判断声音，五个 WAV 和运行时 AudioSource／静音检查单独验收。

本地证据：已忽略的 `outputs/agent-battle/resource-feedback-20261102/`；原始帧位于隔离工程 `outputs/agent-battle/map-ui-20261102/project-tuanjie/outputs/agent-battle/resource-feedback-20261102/`。
