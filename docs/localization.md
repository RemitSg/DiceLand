# 游戏多语言

主菜单的「设置 → 游玩与反馈 → 语言」提供简体中文和 English。保存后应用，并写入 main_menu_settings.json。旧设置默认简体中文。英文覆盖主菜单、能力树和制作人员、地图探索与各面板、全部教学战脚本、地图事件与副本、战斗详情、战斗结算和整局结算。缺少译文的内容显示原文。

## 译表和打包

团结 1.8.4 使用 Localization 1.5.3。通过 **Window > Asset Management > Localization Tables** 编辑 DiceLand 表集合，源资产位于 Assets/Localization/Tables。静态标签用稳定语义键调用 GameText.Get。动态整句用 GameText.Format 和具名参数，两列保留同名参数。译文可调整语序。金币、行动点和状态可用 [[DL_Money|Gold]] 这样的标记保留颜色与图标。

资产与教学脚本的原文保留在现有配置。中文显示读取当前原文，中文表列供翻译和校对。英文在显示时按固定键取值。敌人、技能与状态的同编号变体可显式填写 localizationKey。新增技能时为技能资产指定独立的 localizationKey，并补齐名称和描述。更新文案后同步译表的原文与英文列。

事件使用 eventId、optionId 和 resultId 定位标题、叙事、预览与结果。地图副本使用 dungeonId 和格子索引。教程使用 stepId 或 reactionId，覆盖标题、正文和拦截操作时的提示。编辑事件流程时应保留既有标识，并检查后续事件和随机分支。

译表以本地 Addressables 组随游戏构建。导入改动后，构建对应平台的 Addressables 内容并验证启动、往返切换、读档、事件分支与结算。运行回归包含双语条目和参数检查、全部事件与技能的译文覆盖、英文技能详情生成，以及正式场景里的旧档恢复。

## 存档与机制标识

角色用 characterId 和旧档别名恢复；新手木剑、史莱姆粘液和零编号绿史莱姆敌群也有固定存档 ID 与旧别名。重新保存写入固定资产 ID，保留原队员实例 memberId。地图存档目录会沿已分配事件查找后续事件，以恢复分支引用。

蛛孕、噬亲、融入暗影和赌博继续使用 BattleSkillMechanic 触发。教学战指定角色授技使用角色 ID。译表新增的文本键只用于显示。

地图事件正文和选项，以及敌人、技能、遗物、状态和装备文案已对照原文校对，修正了专名、条件、数量关系与不自然的表述。术语统一使用 Speed、Speed Slot、Power、Energy、Clash、One-Sided Attack 和 AP。离线检查 Unity YAML 时需正确解析多行标量，不能把序列化折行当成译文结束。

正式技能的 215 个显示名与能力树 33 个节点均已逐项校对，敌群使用对应成员的英文名称。命名调整只改译表，战斗机制与存档继续使用既有标识。能力树的 Man 节点原文误写 Molly、图纸节点误写卷轴，已按实际配置修正这三处中文显示字段；节点 ID、费用、前置关系和效果不变。制作人员保留作者本人的姓名，职责与说明使用英文。

ResourceKeywordText 同时识别中英文资源、属性与完整状态名。英文按单词边界识别，支持大小写和临时状态名称，复用同一组图标、颜色和 dl-resource 标识。译表中的状态名变更后须同步英文别名，StatusKeywordVisualTests 会逐一检查全部英文状态名与资产图标的对应关系。新增语言时也需要维护对应的关键词别名。

Poison 同时是毒属性和中毒状态的英文名称。属性展示使用 ResourceKeywordText.AttributeLabel 生成带属性标识的文本，状态文案直接使用 Poison。可通过 [[DL_Attribute_Poison|Poison]] 或 [[DL_Status_Poison|Poison]] 显式指定语义。解析后的重复格式化保留原标识和图标。

PlayMode 回归覆盖设置往返切换、旧档继续游戏、全部地图事件选项、低语井副本出入、休息区四个交互、七套教学脚本与英文战斗详情。通关用例通过真实 Boss 战斗和奖励入口抵达胜利总分并返回主菜单，测试通过控制生命和强壮层数固定战斗结果。

延迟状态的时间短语在整句中按英文语序组合。全量技能详情检查同时读取完整说明与悬停简版，检查目标、时间和动作之间的边界，防止跨片段拼句时连字。

动态数量使用 SmartFormat 的 plural 格式选择单复数。同一个参数既可显示带颜色的数量，也可用于词形选择；GameText.Format 为带富文本的数字保留显示样式，并向单复数规则提供数值。区间和符号数量使用复数形式。不要在译文里固定写成「{count} stacks」。

准备按钮与胜利入场图原本包含烘焙的中文字。英文模式使用同一按钮上的通用框体和可翻译标签，以及共用入场缩放、淡入时序的胜利文字。中文继续使用原图。新增带文字的美术时须检查实际画面，静态译表与 Text 组件检查无法发现图片内的漏译。
