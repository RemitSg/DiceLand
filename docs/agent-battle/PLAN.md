# Agent 完整游戏闭环开发计划

目标：agent 通过公开、无图形的接口，按照正式游戏规则，从创建冒险开始，自主探索、战斗、获取和使用资源，最终胜利、失败或放弃并完成结算；随后可以保存恢复、重放以及开始下一局。

## 不变条件

- 正式界面与接口共用玩法实现，不复制伤害、遗物、地图、经济或结算公式。
- 正式内容与正常难度是完成门槛。小型场景、测试数据和强制结果只能用于定向测试，不能证明完整闭环完成。
- 合法行动来自当前真实状态。非法、过期、重复请求不能重复消耗资源或产生奖励。
- 不覆盖用户场景或真实存档。测试的局外成长和保存位置必须隔离，持久化行为可明确选择。
- 每批有可检查的目标、验证证据和独立 Git 提交。提交仅包含该批文件，保留工作区中的用户变更。
- 不以无窗口 Unity 宿主冒充独立 .NET 内核。先完成共享规则闭环，再按收益迁移规则模块。
