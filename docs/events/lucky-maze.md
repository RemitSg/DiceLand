## 进入与移动

- 主地图入口选择“好吧，我试试。”后进入副本。入口两个选项选择后均完成该主地图事件。
- 副本起点只允许向第一个事件格“盥洗室”移动；该次移动和后续格子跳转均不消耗行动点。
- 首个事件触发后禁止自由移动。选择选项、阅读故事结果并点击“继续”后，角色直接跳到对应事件格，自动打开该格事件。
- 回到已访问的房间仍可重新选择选项，格子跳转不累计事件窗口的嵌套深度。休息室的完成选项领取原有遗物奖励后，经右侧出口返回主地图。

## 奖励与显示

- `033` 入口及十个房间均隐藏选项后果说明、后果预览和单独的效果结果区，保留选项文字与故事结果正文。
- 每个格子的每个选项仅首次成功执行时发放奖励。再次选择相同选项仍正常跳转，但不会重复获得金币、战利品、治疗或最终遗物。不同房间分别记录。
- 原有扣钱、扣血及支付条件继续生效；重复选择失败选项不会免除惩罚。
- 奖励记录保存在格子数据的 `claimedEventOptionRewards`，包含事件 ID 与选项 ID；移动锁保存在副本上下文的 `eventNavigationStarted`。两者均参与存档和快照克隆，副本选项成功后立即保存领取状态。
- 普通事件和未启用这些规则的其他特殊副本沿用原有行为。
